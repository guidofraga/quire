# Quire documentation

For people working on Quire. Start with [CONTRIBUTING.md](../CONTRIBUTING.md) to get set up, then read what your change touches.

| Page | Read it when |
|---|---|
| [01 — Architecture](01-architecture.md) | You want to know why Quire is built this way: Tauri and Rust, the engine's layers, rendering, the roadmap |
| [02 — File format](02-file-format.md) | You change what a document or notebook holds, or read `.quire` files from other tools |
| [03 — Code map](03-code-map.md) | You are looking for where something lives, or how an edit becomes a result on the page |
| [04 — Guidelines](04-guidelines.md) | You are writing code, CSS or words the user reads; recipes for adding functions, units, commands, backend calls and region kinds |
| [05 — Testing](05-testing.md) | You are adding or fixing tests, or one is flaky |
| [06 — Releasing](06-releasing.md) | You are shipping a version (maintainers) |

Keep these pages true: a change that moves code, adds a convention or changes a process updates the page that describes it in the same commit.
